# 自訂回合計時小幫手

## 概覽
提供需要掌握固定回合節奏的使用者一個清楚、可靠的單頁倒數工具。預設每回合 5 分鐘，在剩餘 1 分鐘、30 秒與結束時響鈴，也能依現場需求調整。

## 使用者與情境
- 主持人、教師、教練與活動工作者可快速開始、暫停、繼續或重設回合。
- 使用者可自訂回合總時間及前兩次倒數提示點；第三次固定在結束時提醒。
- 使用者可隨時按「立即響鈴」，不受倒數狀態限制，也不改變計時進度。
- 設定保存在目前裝置，重新開啟後仍可沿用。

## 設計方向
採低干擾的專注工具風格，以深青綠色建立穩定感，搭配琥珀色重點與大型等寬數字。單頁介面同時照顧桌面與手機操作，提示發生時提供明確但短暫的視覺回饋。

## 使用限制
- 不依賴外部資料或網路服務。
- 提示音由瀏覽器在本機產生，可離線使用。
